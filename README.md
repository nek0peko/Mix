# Mix Reborn

**2026 持续更新中 · 当前版本 v2.3.0**

基于 [Mix 2.0.0](https://github.com/wibus-wee/Mix/tree/v2.0.0) 继续维护的 Typecho 主题

Wibus 佬已停止维护原版，原版本未适配 Typecho 1.2 系列。Mix Reborn 保留原有的布局与设计风格，继续完善新版 Typecho 的兼容性、外观设置和使用体验

## 使用指南

1. 将本仓库中的 `Mix` 文件夹放入 Typecho 的 `usr/themes/` 目录，最终路径为 `usr/themes/Mix/`
2. **可选：友链插件**。将本仓库中的 `Links` 文件夹放入 `usr/plugins/` 目录，最终路径为 `usr/plugins/Links/`，然后在后台「控制台 → 插件」启用 Links 插件，在「管理 → 友情链接」添加友链
3. 在 Typecho 后台「控制台 → 外观」启用 Mix 主题，然后在该页面点击「设置外观」，详细配置博客信息、导航栏、首页模块、背景和部件，完成后点击「保存设置」
4. **可选：独立友链页面**。创建独立页面，模板选择「友链页面」，可设置隐藏以避免出现在导航栏下拉框中；发布后在「设置外观 → 导航栏设置 → 友链页面链接」填入页面地址

## 主题特色

| 特色 | 说明 |
| --- | --- |
| 独特的布局风格 | 保留 Mix 的顶部导航、博主信息区与模块化首页布局，适配桌面和手机浏览 |
| 两种首页布局 | 可选择小卡片或纯文字列表，按内容与阅读习惯调整 |
| 两种文章样式 | 支持普通文章与日记样式，可为单篇文章选择 |
| 常用短代码 | 支持图集、折叠、标签、选项卡、播放器与防剧透等内容，兼容部分 handsome 短代码写法 |
| 阅读辅助 | 分类树抽屉支持筛选与定位当前文章，文章目录跟随阅读位置，提供代码高亮与日夜模式 |
| 全站搜索 | 顶部导航支持搜索入口，搜索结果以图文卡片展示，标题与摘要高亮关键词 |
| 可编排的首页 | 图标与导航链接可增删，超链模块可独立启用并调整顺序 |
| 友链展示 | 配合 Links 插件，在首页展示友链，也可创建独立的友链页面 |
| 局部页面跳转 | 默认使用无需依赖 jQuery 的 MoOx Pjax，保留 jQuery Pjax 选项 |
| 外观与部件配置 | 博客信息、背景、备案号、导航栏搜索、转载授权、评论区、实时在线人数等均可按需设置 |
| 设置备份 | 支持将主题设置备份到数据库，并从备份还原 |

## 更新日志
