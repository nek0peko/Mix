# Mix Reborn

**2026 持续更新中 · 当前版本 v2.1.0**

基于 [Mix 2.0.0](https://github.com/wibus-wee/Mix/tree/v2.0.0) 继续维护的 Typecho 主题

Wibus 佬已停止维护原版，原版本未适配 Typecho 1.2 系列。Mix Reborn 保留原有的布局与设计风格，继续完善新版 Typecho 的兼容性、外观设置和使用体验

## 主题特色

| 特色 | 说明 |
| --- | --- |
| 独特的布局风格 | 保留 Mix 的顶部导航、博主信息区与模块化首页布局，适配桌面和手机浏览 |
| 两种首页布局 | 可选择小卡片或纯文字列表，按内容与阅读习惯调整 |
| 两种文章样式 | 支持普通文章与日记样式，可为单篇文章选择 |
| 常用短代码 | 支持图集、折叠、标签、选项卡、播放器与防剧透等内容，兼容部分 handsome 短代码写法 |
| 阅读辅助 | 提供文章目录、代码高亮与日夜模式 |
| 可编排的首页 | 图标与导航链接可增删，超链模块可独立启用并调整顺序 |
| 友链展示 | 配合 Links 插件，在首页展示友链，也可创建独立的友链页面 |
| 局部页面跳转 | 默认使用无需依赖 jQuery 的 MoOx Pjax，保留 jQuery Pjax 选项 |
| 外观与部件配置 | 博客信息、背景、备案号、转载授权、评论区、在线人数等均可按需设置 |
| 设置备份 | 支持将主题设置备份到数据库，并从备份还原 |

## 更新日志

### v2.1.0

- **支持 Typecho v1.2.0 及以上**
- **设置外观页全面优化**
  - 界面美化：统一间距、按钮与输入框样式，完善手机端布局，保留 Typecho 原生后台风格
  - 性能优化：依赖本地加载、脚本延后执行、减少重复更新，优化静态资源缓存
  - 分组优化：重新整理导航、背景、样式、部件等设置，合并博客标题，新增 ICP 备案号配置
  - 首页图标：表单式添加和删除，支持自定义图标与跳转链接，链接留空不显示
  - 顶部右侧模块：表单式添加和删除，支持自定义图标、链接及新标签页打开
  - 在线人数：显示在浏览器标题与博客底部，统计文件缺失或权限不足时自动降级，不影响页面访问
  - 设置备份：集中保存与备份操作，明确备份、还原和删除的含义，增加操作确认
- **首页自定义超链模块**
  - 表单式配置模块及链接，无需手写 JSON，支持添加、删除和上下排序
  - 每个模块可独立开关，关闭后保留内容，排序提供平滑动画
  - 内置友链模块支持自定义标题、开关与排序，默认置于底部，仅在 Links 插件启用时展示相关设置
- **随机猫猫头像**：评论头像由 Gravatar 改为猫猫头，友链未填写头像时也使用随机猫猫头
- **回复后可见**：支持 `[hide]要隐藏的内容[/hide]`，访客评论审核通过后可查看隐藏内容
- **分类页完善**：增加文章分类页分页与分类描述，首页每个分类展示 8 篇文章
- **首页与文章页加载优化**：调整 CDN 资源来源、压缩 JS 与图片，减少资源加载时间
- **文章缩略图优化**：正则匹配文章中的第一张图片链接，支持 PNG、JPG、JPEG；无图片时使用随机缩略图，范围调整为 22 张
- **Bug 修复**
  - 文章目录：修正右侧目录标签闭合与嵌套错误
  - 文章缩略图：修复取错文章 ID 导致首图无法显示、无图片时访问空数组产生警告，以及随机图片范围超出实际数量的问题
  - 图标显示：修复加载画面的自定义导航图标不生效，补充 iOS 网站图标适配
  - Debug 模式：修复调试函数读取未定义变量及输出逻辑错误
  - 设置页：修复欢迎区头像未正确读取、点击后弹窗持续加载及表单提交异常，纠正配置说明中的左右位置错误
  - 列表编辑：修复删除全部项目后按钮间距消失、排序按钮未居中，以及快速输入后保存可能遗漏最后修改的问题
  - 页面跳转：修复新标签页链接被 Pjax 拦截，以及点击首页图标同时触发图片预览的问题
  - 友链页面：修复插件未启用时仍调用插件、友链入口留空仍显示，以及评论区不遵循部件开关的问题
  - 配置兼容：兼容旧版部件设置与备份，确保关闭模块后保留配置，完善空值处理和链接校验
  - 内容显示：补充博主信息和链接的输出转义，修复背景图片地址含特殊字符时样式出错的问题
  - 在线统计：修正统计文件路径与显示逻辑，避免并发读写冲突，文件缺失、权限不足或被占用时不再阻塞页面
